Sistem manajemen barang/inventory berbasis web yang dibangun dengan PHP native untuk mengelola data barang secara efisien.

##  Deskripsi

Sistem ini merupakan aplikasi web untuk manajemen data barang yang mencakup fitur login, dashboard, tambah barang, dan daftar barang. Dilengkapi dengan autentikasi pengguna dan manajemen session.
